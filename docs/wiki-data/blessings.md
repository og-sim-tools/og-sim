# Dragon’s Blessing

_Transcribed from the Overgeared Hero wiki ([Dragon's Blessing](https://overgearedhero.fandom.com/wiki/Dragon's_Blessing)) on 2026-10-15. Wiki data is unverified; see REVIEW.md for known problems._

**Blessings are per hero.** Each hero has their own blessing slots. Hero-exclusive (unique) blessings can only be rolled on their own hero; linking that hero’s skill to another hero does not unlock them.

I enter the exact value of each blessing I own. Common and class blessings roll inside a range per rarity; unique blessings have one fixed value per rarity.
